# Moulham DevTools | أدوات المطورين الاحترافية 🚀

منصة ويب متكاملة ومجانية للمطورين، تضم مجموعة من الأدوات البرمجية الأساسية التي تعمل بالكامل محلياً داخل المتصفح (Client-side) مع أولوية قصوى للخصوصية وسرعة الأداء.

## ✨ المميزات الرئيسية:
- **خصوصية تامة:** جميع العمليات تتم داخل متصفحك ولا يتم إرسال أي بيانات لخوادم خارجية.
- **تعدد اللغات:** يدعم التبديل السلس بين اللغة العربية والإنجليزية (`RTL` و `LTR`).
- **الثيمات:** دعم الوضع الداكن (Dark Mode) والأنيق (Light Mode).
- **التصميم:** واجهة عصرية جذابة مزودة بشعارات نيون وتوقيع احترافي.

## 🛠️ الأدوات المتاحة حالياً:
1. **JSON Formatter** (تنسيق وفحص ملفات JSON).
2. **Base64 Encoder / Decoder** (تشفير وفك تشفير النصوص).
3. **URL Encoder / Decoder** (ترميز وفك ترميز الروابط).
4. **Hash Generator** (توليد بصمات MD5 و SHA-256 / SHA-1).
5. **HTML Entities Converter** (تحويل رموز HTML الخاصة والعكس).
6. **UUID Generator** (توليد معرفات فريدة UUID v4).
7. **Password Generator** (إنشاء كلمات مرور قوية وآمنة).
8. **Unix Timestamp Converter** (تحويل التواريخ وأختام الوقت).
